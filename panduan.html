Panduan Setup dari Awal

Gak perlu ngoding, ikutin aja step-nya satu-satu. Ini buat kamu yang baru pertama kali pakai ManzXSub.

1

Buka website & masukin username TikTok

Buka halaman utama ManzXSub, isi username TikTok kamu (tanpa @). Ini bukan login asli, cuma dipake buat bikin dashboard sendiri.

Buka Setup
2

Lanjut dari Member Pass ke Dashboard

Setelah isi username, bakal muncul kartu member kamu. Tinggal tap "Lanjut ke Dashboard →".

3

Atur Timer, Milestone, dan Alert

Di dashboard ada 3 tab pengaturan. Atur sesuka kamu — menit per coin, goal, sampe warna & font alert. Jangan lupa tap Simpan tiap habis ubah.

4

Copy link overlay, tempel ke software streaming

Tiap tab (Timer/Milestone/Alert) punya link sendiri. Tap "Copy Link", terus tempel sebagai Browser Source di OBS, atau di aplikasi overlay Android kamu.

5

Download & jalanin Bot Termux

Ini bagian yang nyambungin gift TikTok asli ke overlay kamu. Download filenya, install Termux dari Play Store/F-Droid, terus jalanin perintah ini:

pkg install nodejs
npm install tiktok-live-connector
node bot.js

⬇ Download bot.js
6

Live streaming!

Nyalain live TikTok kamu seperti biasa. Begitu ada yang ngirim gift, timer/alert/milestone bakal update otomatis di overlay, ALERT!! ( Pastikan akun lo udah live baru jalanin kode JS nya do termux, Kalo lu maksa jalanin pas belum live bakalan error dan gak bisa di pakai ).

6
